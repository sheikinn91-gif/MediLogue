# 🏥 MediLogue: Universal Dialect & Triage Engine

MediLogue is an AI-driven healthcare translation and automated triage routing platform designed to bridge communication gaps between rural patients and medical professionals. By converting localized phonetic dialects and sign language cues into standardized medical data, the system ensures rapid, accurate, and equitable emergency care categorization.

## 🚀 Key Features

- **Vocal Node:** Captures and translates deep colloquial and regional phonetic dialects into clinical English.
- **Vision Link:** Tracks hand landmark structures to interpret local medical sign language streams.
- **Agentic Triage Engine:** Cross-references dynamic patient demographic risk factors and objective biometrics using Advanced LLMs.

## 🧠 Technical Architecture & Ecosystem

The intelligence layer of MediLogue is powered exclusively by **Alibaba Cloud DashScope API**, leveraging the flagship **Qwen Large Language Models (Qwen-Max)** for structured clinical reasoning and multi-modal semantic mapping.

- **Frontend:** React, TypeScript, Tailwind CSS (High-Density Clinical HUD Interface)
- **Backend Framework:** Python, FastAPI Architecture
- **Core AI Engine:** Alibaba Cloud SDK & Qwen-Max Model Inference
